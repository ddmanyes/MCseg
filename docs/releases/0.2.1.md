# MCseg 桌面版 0.2.1：H&E 色彩解卷積修正

日期：2026-09-20。

修正 `backend/src/segmentation/cellpose_runner.py::color_deconvolution_he`
多餘的逆矩陣轉置。染色向量是 rows，故 `OD = C @ M`，
`C = OD @ inv(M)`。詳見 `docs/color_deconvolution_fix.md`。

桌面殼版本由 0.2.0 升至 0.2.1（Tauri config、Cargo manifest/lock 同步），
讓 bootstrap 的 `.resource_version` 比對觸發後端資源更新。
Python API health 的 0.8.0 是另一個版本欄位，不代表桌面殼升級失敗。
歷史分割結果不會自動改變；本次沒有重新評估 b00 或 AP。

## Windows PC 接續

本次尚未在 Windows 建置或驗收 0.2.1。既有 0.2.0 EXE 不含本次修正。
Windows checkout 優先從 Git 取得更新，在 repository 根目錄執行：

```powershell
git status --short
git fetch origin
git switch feat/tauri-desktop-packaging
git pull --ff-only origin feat/tauri-desktop-packaging
```

若工作區有未提交變更或無法 fast-forward，先處理差異，不要強制覆蓋。
確認 `frontend/src-tauri/tauri.conf.json` 版本為 `0.2.1`。
已從 Git 拉取更新後不必再套 patch。`release/` 為本機產物目錄，
DMG、EXE、manifest 與 patch 均未納入 Git；Windows 安裝檔須在 PC 建置。

離線備用方式：使用目前同一份 MSseg 原始碼即可建置；若使用另一份 checkout，先將
`release/mcseg-0.2.1-source.patch` 複製過去，在 repository 根目錄執行：

```powershell
git status --short
git apply --check .\release\mcseg-0.2.1-source.patch
git apply .\release\mcseg-0.2.1-source.patch
```

修補檔基於 `6dcaa4074226c8f95f76a6b1db868bd8fc487221`
（`feat/tauri-desktop-packaging`），只含本次色彩修正、回歸測試、版本與紀錄。
若 `--check` 失敗，先核對版本及本機差異；不要強制覆蓋。
若已使用此次更新的共享資料夾，略過套 patch，避免重複套用。

關閉舊版 MCseg，確認沒有正在執行的分析，再建置：

```powershell
cd frontend
npm ci
npm run tauri:build:windows
cd ..
Get-FileHash .\release\mcseg_0.2.1_x64-setup.exe -Algorithm SHA256
```

沿用已建立的 Windows Node/Rust/MSVC 建置環境。腳本會使用 Windows Cargo
target，必要時取得 uv sidecar，僅產出 NSIS EXE，並複製到 `release/`。

安裝後啟動新版，完成 bootstrap，再核驗實際執行期資源：

```powershell
$runtime = Join-Path $env:APPDATA 'com.mcseg.app\app'
Get-Content (Join-Path $runtime '.resource_version')
Get-FileHash (Join-Path $runtime 'backend\src\segmentation\cellpose_runner.py') -Algorithm SHA256
Get-FileHash .\backend\src\segmentation\cellpose_runner.py -Algorithm SHA256
Invoke-RestMethod http://127.0.0.1:8001/api/health
```

驗收：marker 為 `0.2.1`、兩個 Python SHA-256 相同、health 正常；
確認 UI 能開啟並正常關閉後端。另以自選小 ROI 驗證 H&E 分割；
保存新輸出，不覆蓋歷史基準。將 EXE 大小、SHA-256、安裝及測試結果
補回 SB「MSseg Tauri 桌面應用打包計畫與審查」。
